# ReservaYa Ayacucho · Sistema de reservas de canchas sintéticas
 ## nombre
 PRADO GOMEZ EDHTS YHURDIN
## Descripción
 Plataforma para buscar, reservar y pagar canchas sintéticas en los distritos de Huamanga (Ayacucho, Carmen Alto, San Juan Bautista, Jesús Nazareno, Andrés Avelino Cáceres), con disponibilidad en tiempo real, mapa de locales con rutas en Google Maps y Waze, pagos por Yape/Plin y un asistente con inteligencia artificial.
 ## Caso de estudio
 Locales de canchas sintéticas de Huamanga que hoy reciben sus reservas por WhatsApp y llamadas.

 Arquitectura de Software
