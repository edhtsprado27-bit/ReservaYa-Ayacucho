# Atributos de calidad

| ID | Atributo de calidad | Escenario de calidad |
|---|---|---|
| AC01 | **Rendimiento** | La búsqueda de canchas y la consulta de disponibilidad deben responder rápidamente, incluso en las horas de mayor demanda (noches y fines de semana). |
| AC02 | **Consistencia** | Dos jugadores no deben poder reservar el mismo horario de la misma cancha, aunque lo intenten al mismo tiempo. |
| AC03 | **Disponibilidad** | El sistema debe permanecer disponible para que los jugadores puedan reservar en cualquier momento del día. |
| AC04 | **Seguridad** | Los datos de los usuarios, las reservas y los comprobantes de pago deben estar protegidos frente a accesos no autorizados. |
| AC05 | **Mantenibilidad** | El sistema debe permitir cambiar un módulo (por ejemplo, el modelo de IA) sin afectar innecesariamente otras funcionalidades. |
| AC06 | **Usabilidad** | Un jugador debe poder completar una reserva desde el celular en pocos pasos. |
