# Decisiones arquitectónicas (ADR)

Registro de las decisiones de arquitectura. Cuando una decisión cambia, **no se borra**: se marca como *Reemplazada* y se agrega la nueva, con el motivo. Así queda la historia de por qué el sistema es como es.
